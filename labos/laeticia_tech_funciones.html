💡 ¿QUÉ ES UNA FUNCIÓN?

Una función es un bloque de código que realiza una tarea específica. Se define con def y se puede reutilizar muchas veces.

Ejemplo: def sumar(a, b): return a + b crea una función que suma dos números.
